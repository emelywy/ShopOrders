# Реєстр технічного боргу ShopOrders

Ставка для оцінки вартості — 300 грн/год (як у лабораторній роботі 7).

## Погашений борг лабораторних робіт

| ID | Опис | Як погашено |
|---|---|---|
| TD-01 | Форматування чисел залежало від культури ОС | інваріантна культура в повідомленнях і `Display.Money` (рішення 07) |
| TD-02 | Опис клієнта читав `DateTime.Now` | час береться лише з `IClock`; у тестах — `FixedClock` |
| TD-03 | Коди помилок передавалися магічними рядками | `DomainRuleException.Rule` і константи `RuleCodes` |
| TD-04 | Не було тесту на межі 1000 грн | рядки 999.99 / 1000 / 4999.99 / 5000 у `TieredDiscountPolicyTests` |
